# External Users

## Purpose

The **External Users** section in ViciECM allows administrators to manage existing external user access by updating the expiry time and viewing the assigned access level.

## Features

### 1. View External Username
Displays the existing external username. This field is read-only and cannot be modified.

### 2. Update Expiry Time
Allows administrators to modify the expiry date and time. This is a mandatory field.

### 3. View Access Level
Displays the assigned access level (**Read** or **Edit**). The access level cannot be modified from this section.

### 4. View External User Details
Displays information such as the username, mode, logical path, job name, workflow name, and expiry time.

### 5. Edit External User Settings
Allows administrators to modify the expiry time using the Edit (pencil) icon corresponding to an existing entry.

## How to Update an External User

### Step 1: Navigate to External Users
Navigate to **Administration → External Users**.

### Step 2: Locate the External User
Locate the external user whose settings need to be updated.

### Step 3: Edit External User Details
Click the **Edit (pencil) icon** in the corresponding row.

### Step 4: View External Username
View the **External Username**. The username cannot be edited.

### Step 5: View Access Level
View the assigned **Access** level (Read or Edit). This field is displayed for reference only and cannot be changed.

### Step 6: Update Expiry Time
Enter or select the required **Expiry Time** using the date and time fields. This field is mandatory.

### Step 7: Save Changes
Click **Update** to save the changes.

### Step 8: Cancel Changes
Click **Cancel** to discard the changes.
## Access Levels

### 1. Read Level Access gives you the following permissions:

- Search
- View
- Print
- Download

### 2. Edit Level Access gives you the following permissions:

- Search
- View
- Print
- Download
- Modify Documents
- Add Annotations
