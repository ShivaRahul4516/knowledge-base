## 4. CSS Selectors

CSS selectors identify elements using HTML tags, IDs, classes, attributes and relationships.

In Playwright Python:

```python
page.locator("CSS_SELECTOR")
```

### 4.1 Locate by ID

An ID selector uses `#` followed by the element's ID.

**Example 1 – Username**

HTML:
```html
<input
    id="username"
    type="text"
>
```

Playwright:
```python
page.locator("#username").fill("admin")
```

**Example 2 – Login Button**

HTML:
```html
<button id="loginBtn">Login</button>
```

Playwright:
```python
page.locator("#loginBtn").click()
```

**Example 3 – Search Field**

HTML:
```html
<input id="searchBox" type="search">
```

Playwright:
```python
page.locator("#searchBox").fill("Invoice")
```

### 4.2 Locate by Class

A class selector uses `.` followed by the class name.

**Example 1 – Save Button**

HTML:
```html
<button class="save-button">Save</button>
```

Playwright:
```python
page.locator(".save-button").click()
```

**Example 2 – Multiple Classes**

HTML:
```html
<button class="btn primary save-button">
    Save
</button>
```

Playwright:
```python
page.locator(
    ".btn.primary.save-button"
).click()
```

**Example 3 – Input Field**

HTML:
```html
<input class="form-control">
```

Playwright:
```python
page.locator(
    ".form-control"
).fill("admin")
```

### 4.3 Locate by Tag Name

A tag selector identifies elements using their HTML tag.

**Example 1 – Button**

HTML:
```html
<button>Save</button>
```

Playwright:
```python
page.locator("button").count()
```

**Example 2 – Input**

HTML:
```html
<input type="text">
```

Playwright:
```python
page.locator("input").count()
```

**Example 3 – Table**

HTML:
```html
<table id="documentTable">
    <tr><td>Invoice.pdf</td></tr>
</table>
```

Playwright:
```python
page.locator("table").count()
```

### 4.4 Locate by Attribute

Attribute selectors identify elements using their HTML attributes.

**Example 1 – Name Attribute**

HTML:
```html
<input
    type="text"
    name="username"
>
```

Playwright:
```python
page.locator(
    'input[name="username"]'
).fill("admin")
```

**Example 2 – Type Attribute**

HTML:
```html
<input type="password">
```

Playwright:
```python
page.locator(
    'input[type="password"]'
).fill("password123")
```

**Example 3 – Placeholder Attribute**

HTML:
```html
<input placeholder="Search Documents">
```

Playwright:
```python
page.locator(
    '[placeholder="Search Documents"]'
).fill("Invoice")
```

**Example 4 – Data Attribute**

HTML:
```html
<button data-action="delete">
    Delete
</button>
```

Playwright:
```python
page.locator(
    '[data-action="delete"]'
).click()
```

**Example 5 – Partial Attribute Matching**

HTML:
```html
<input
    name="user_email"
    type="text"
>
```

Playwright:
```python
page.locator(
    'input[name^="user"]'
)
```

CSS attribute operators:

| Operator | Meaning | Example |
|---|---|---|
| `=` | Exact match | `[type="text"]` |
| `^=` | Starts with | `[name^="user"]` |
| `$=` | Ends with | `[name$="email"]` |
| `*=` | Contains | `[name*="user"]` |
| `~=` | Contains a whitespace-separated word | `[class~="active"]` |
| `|=` | Exact value or value followed by a hyphen | `[lang|="en"]` |

### 4.5 Combining CSS Selectors

Multiple selectors can be combined to narrow down the target.

**Example 1 – Tag and ID**

HTML:
```html
<input id="username" type="text">
```

Playwright:
```python
page.locator("input#username")
```

**Example 2 – Tag and Class**

HTML:
```html
<button class="save-button">Save</button>
```

Playwright:
```python
page.locator("button.save-button")
```

**Example 3 – Tag and Attribute**

HTML:
```html
<input type="text" name="username">
```

Playwright:
```python
page.locator(
    'input[type="text"][name="username"]'
)
```

**Example 4 – Parent and Child**

HTML:
```html
<div class="login-form">
    <input name="username">
</div>
```

Playwright:
```python
page.locator(
    ".login-form input"
).fill("admin")
```

**Example 5 – Direct Child**

HTML:
```html
<div class="login-form">
    <input name="username">
</div>
```

Playwright:
```python
page.locator(
    ".login-form > input"
).fill("admin")
```

The space selector matches descendants at any depth. The `>` selector matches only direct children.

### 4.6 CSS Pseudo-Classes

CSS pseudo-classes allow elements to be identified based on their position or state.

**Example 1 – First Child**

HTML:
```html
<ul>
    <li>Administration</li>
    <li>Users</li>
    <li>Groups</li>
</ul>
```

Playwright:
```python
page.locator(
    "ul li:first-child"
).click()
```

**Example 2 – Last Child**

Playwright:
```python
page.locator(
    "ul li:last-child"
).click()
```

**Example 3 – Nth Child**

Playwright:
```python
page.locator(
    "ul li:nth-child(2)"
).click()
```

**Example 4 – Checked Checkbox**

HTML:
```html
<input type="checkbox" checked>
```

Playwright:
```python
page.locator(
    'input[type="checkbox"]:checked'
).count()
```

**Example 5 – Enabled Input**

HTML:
```html
<input type="text">
<input type="text" disabled>
```

Playwright:
```python
page.locator(
    "input:enabled"
).count()
```

## 5. XPath Locators

XPath is a query language used to navigate and identify elements in an HTML or XML document.

XPath can identify elements using tags, attributes, text, parent-child relationships, ancestors and siblings.

In Playwright Python:

```python
page.locator("xpath=EXPRESSION")
```

Playwright also recognises XPath expressions passed directly to `locator()` when they begin with `//` or `..`.

### 5.1 XPath Using Tag Name

HTML:
```html
<button>Save</button>
<button>Cancel</button>
```

Playwright:
```python
page.locator("//button").count()
```

### 5.2 XPath Using ID

HTML:
```html
<input id="username" type="text">
```

Playwright:
```python
page.locator(
    '//*[@id="username"]'
).fill("admin")
```

### 5.3 XPath Using Class

HTML:
```html
<button class="save-button">
    Save
</button>
```

Playwright:
```python
page.locator(
    '//button[@class="save-button"]'
).click()
```

For multiple class names, use a class-token expression:

HTML:
```html
<button class="btn primary save-button">
    Save
</button>
```

Playwright:
```python
page.locator(
    '//button[contains(concat(" ", normalize-space(@class), " "), " save-button ")]'
).click()
```

### 5.4 XPath Using Text

HTML:
```html
<button>Save Document</button>
```

Playwright:
```python
page.locator(
    '//button[text()="Save Document"]'
).click()
```

Partial text:

```python
page.locator(
    '//button[contains(text(), "Save")]'
).click()
```

Text with surrounding whitespace:

```python
page.locator(
    '//button[normalize-space(.)="Save Document"]'
).click()
```

### 5.5 XPath Using Multiple Attributes

HTML:
```html
<input
    type="text"
    name="username"
    class="form-control"
>
```

Playwright:
```python
page.locator(
    '//input[@type="text" and @name="username"]'
).fill("admin")
```

Another example:

HTML:
```html
<button
    type="button"
    title="Refresh Documents"
>
    Refresh
</button>
```

Playwright:
```python
page.locator(
    '//button[@type="button" and @title="Refresh Documents"]'
).click()
```

### 5.6 XPath Using Parent and Child Relationships

HTML:
```html
<div class="login-form">
    <input type="text" name="username">
    <input type="password" name="password">
</div>
```

Playwright:
```python
page.locator(
    '//div[@class="login-form"]//input[@name="username"]'
).fill("admin")
```

Direct child:

```python
page.locator(
    '//div[@class="login-form"]/input[@name="username"]'
).fill("admin")
```

Difference:
- `/` selects a direct child.
- `//` selects a descendant at any depth.

### 5.7 XPath Using Parent Axis

HTML:
```html
<div class="document-row">
    <span>Invoice_001.pdf</span>
</div>
```

Playwright:
```python
page.locator(
    '//span[text()="Invoice_001.pdf"]/parent::div'
).is_visible()
```

### 5.8 XPath Using Ancestor Axis

HTML:
```html
<div class="document-container">
    <div class="document-row">
        <span>Invoice_001.pdf</span>
    </div>
</div>
```

Playwright:
```python
page.locator(
    '//span[text()="Invoice_001.pdf"]/ancestor::div[@class="document-container"]'
).is_visible()
```

### 5.9 XPath Using Following-Sibling

HTML:
```html
<div class="field">
    <label>Username</label>
    <input type="text">
</div>
```

Playwright:
```python
page.locator(
    '//label[text()="Username"]/following-sibling::input'
).fill("admin")
```

### 5.10 XPath Using Preceding-Sibling

HTML:
```html
<div class="field">
    <input type="text">
    <label>Username</label>
</div>
```

Playwright:
```python
page.locator(
    '//label[text()="Username"]/preceding-sibling::input'
).fill("admin")
```

### 5.11 XPath Using Position

HTML:
```html
<div class="documents">
    <button>Open</button>
    <button>Download</button>
    <button>Delete</button>
</div>
```

Playwright:
```python
page.locator(
    '(//div[@class="documents"]/button)[1]'
).click()
```

XPath positions start at 1, unlike Playwright's `nth()`, which starts at 0.

### 5.12 XPath Axes Reference

| Axis | Purpose |
|---|---|
| `parent::` | Selects the parent |
| `child::` | Selects direct children |
| `ancestor::` | Selects ancestors |
| `descendant::` | Selects descendants |
| `following-sibling::` | Selects following siblings |
| `preceding-sibling::` | Selects preceding siblings |
| `following::` | Selects nodes that follow the current node |
| `preceding::` | Selects nodes that precede the current node |
