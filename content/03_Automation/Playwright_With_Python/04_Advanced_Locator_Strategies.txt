## 6. Advanced Locator Techniques

### 6.1 Chaining Locators

Chaining narrows down a search by locating an element inside another locator.

HTML:
```html
<div class="login-form">
    <input name="username">
    <input name="password">
    <button>Login</button>
</div>

<div class="registration-form">
    <input name="username">
    <button>Register</button>
</div>
```

Playwright:
```python
login_form = page.locator(".login-form")

login_form.locator(
    'input[name="username"]'
).fill("admin")

login_form.locator(
    'input[name="password"]'
).fill("password123")

login_form.get_by_role(
    "button",
    name="Login"
).click()
```

The search is restricted to the login form instead of matching inputs across the entire page.

### 6.2 filter()

`filter()` narrows down an existing locator using text or another locator.

HTML:
```html
<div class="document-row">
    <span>Invoice_001.pdf</span>
    <button>Download</button>
</div>

<div class="document-row">
    <span>Invoice_002.pdf</span>
    <button>Download</button>
</div>

<div class="document-row">
    <span>Invoice_003.pdf</span>
    <button>Download</button>
</div>
```

Playwright:
```python
document = page.locator(
    ".document-row"
).filter(
    has_text="Invoice_002.pdf"
)

document.get_by_role(
    "button",
    name="Download"
).click()
```

**Using has:**

HTML:
```html
<div class="document-row">
    <h3>Invoice_001.pdf</h3>
    <button>Download</button>
</div>

<div class="document-row">
    <h3>Invoice_002.pdf</h3>
    <button>Download</button>
</div>
```

Playwright:
```python
document = page.locator(
    ".document-row"
).filter(
    has=page.get_by_role(
        "heading",
        name="Invoice_002.pdf"
    )
)

document.get_by_role(
    "button",
    name="Download"
).click()
```

**Using has_not:**

```python
document = page.locator(
    ".document-row"
).filter(
    has_not=page.get_by_text("Deleted")
)
```

This example excludes rows containing the text `Deleted`.

### 6.3 first

Selects the first matching element.

HTML:
```html
<button>Edit</button>
<button>Edit</button>
<button>Edit</button>
```

Playwright:
```python
page.get_by_role(
    "button",
    name="Edit"
).first.click()
```

### 6.4 last

Selects the last matching element.

```python
page.get_by_role(
    "button",
    name="Edit"
).last.click()
```

### 6.5 nth()

Selects an element using its zero-based position.

HTML:
```html
<button>Edit</button>
<button>Delete</button>
<button>Download</button>
```

Playwright:
```python
page.locator("button").nth(0).click()

page.locator("button").nth(1).click()

page.locator("button").nth(2).click()
```

| Index | Element |
|---|---|
| `nth(0)` | First element |
| `nth(1)` | Second element |
| `nth(2)` | Third element |

**Important:** Use positional selection only when the ordering is known and stable. A change in sorting or page layout can change which element an index identifies.

### 6.6 and_()

`and_()` combines two locators. The resulting locator matches elements that satisfy both conditions.

HTML:
```html
<button title="Save Document">
    Save
</button>

<button title="Cancel Operation">
    Cancel
</button>
```

Playwright:
```python
button = page.get_by_role(
    "button"
).and_(
    page.get_by_title("Save Document")
)

button.click()
```

### 6.7 or_()

`or_()` combines alternative locators.

HTML:
```html
<div class="notification">
    <button>Continue</button>
</div>
```

Alternative page state:
```html
<div class="login-form">
    <button>Sign In</button>
</div>
```

Playwright:
```python
continue_button = page.get_by_role(
    "button",
    name="Continue"
)

login_button = page.get_by_role(
    "button",
    name="Sign In"
)

alternative_button = continue_button.or_(
    login_button
)

alternative_button.first.click()
```

**Important:** If both elements are present, the combined locator can match multiple elements. Check the current page state before interacting with it.

## 7. Handling Multiple Matching Elements

One common issue in automation is when a locator identifies more than one element.

HTML:
```html
<table>
    <tr>
        <td>Invoice_001.pdf</td>
        <td><input id="chkSelect" type="checkbox"></td>
    </tr>

    <tr>
        <td>Invoice_002.pdf</td>
        <td><input id="chkSelect" type="checkbox"></td>
    </tr>

    <tr>
        <td>Invoice_003.pdf</td>
        <td><input id="chkSelect" type="checkbox"></td>
    </tr>
</table>
```

Incorrect implementation:
```python
page.locator("#chkSelect").check()
```

This locator matches multiple checkboxes.

### Step 1 – Count matching elements

```python
checkboxes = page.locator("#chkSelect")

print(checkboxes.count())
```

### Step 2 – Identify the required row

```python
document_row = page.get_by_role(
    "row"
).filter(
    has_text="Invoice_002.pdf"
)
```

### Step 3 – Locate the checkbox inside that row

```python
document_row.locator(
    "#chkSelect"
).check()
```

**Important:** Repeated IDs are invalid HTML. A better application implementation would use a class or a unique identifier for each checkbox. Scoping the locator can work around the issue, but it does not fix the underlying HTML defect.

## 8. Strict Mode Violations

Playwright applies strictness to operations that require a single element. If a locator matches multiple elements, an action such as `click()` can raise a strict-mode violation.

HTML:
```html
<div>Please wait for a short while</div>
<div>Please wait for a short while</div>
```

Playwright:
```python
page.get_by_text(
    "Please wait for a short while"
).click()
```

This can fail because two elements match.

### Step 1 – Count the matches

```python
message = page.get_by_text(
    "Please wait for a short while"
)

print(message.count())
```

### Step 2 – Inspect the matching elements

```python
for index in range(message.count()):
    print(
        index,
        message.nth(index).text_content()
    )
```

### Step 3 – Identify the correct element

Use a parent container, a unique attribute, a role or another condition to narrow down the locator.

### Step 4 – Perform the action

```python
message.first.click()
```

Only use `.first` after verifying that the first element is actually the intended target.

**Remember:** `count()` helps diagnose multiple matches. It does not automatically guarantee that the page will remain unchanged between counting and interacting.
