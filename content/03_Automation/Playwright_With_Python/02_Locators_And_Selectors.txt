# Playwright with Python – Locators and Selectors

## 1. Introduction to Locators

Locators are used to identify elements on a web page so that Playwright can interact with them.

For example, when automating a login page, we need to identify:
- Username input field.
- Password input field.
- Login button.
- Error or success messages.

Playwright provides several ways to identify these elements, including role, label, text, placeholder, test ID, CSS and XPath.

A locator does not permanently store an element. Playwright resolves it against the current page when an action or assertion is performed. This helps locators work with pages that dynamically update.

### Basic Example

**HTML:**
```html
<div class="login-form">
    <label for="username">Username</label>
    <input id="username" type="text">

    <label for="password">Password</label>
    <input id="password" type="password">

    <button type="submit">Login</button>
</div>
```

**Playwright Python:**
```python
from playwright.sync_api import sync_playwright

with sync_playwright() as p:

    browser = p.chromium.launch(headless=False)
    page = browser.new_page()

    page.goto("https://example.com")

    page.get_by_label("Username").fill("admin")
    page.get_by_label("Password").fill("password123")

    page.get_by_role("button", name="Login").click()

    browser.close()
```

**Explanation:**
- `page` represents the browser tab.
- `get_by_label()` identifies the input fields through their labels.
- `get_by_role()` identifies the Login button.
- `fill()` enters text into an input field.
- `click()` performs the button interaction.

---

## 2. Types of Locators in Playwright

| Locator | Purpose |
|---|---|
| `get_by_role()` | Identifies elements by their role and accessible name |
| `get_by_label()` | Identifies form controls through associated labels |
| `get_by_placeholder()` | Identifies input fields using placeholder text |
| `get_by_text()` | Identifies elements using visible text |
| `get_by_alt_text()` | Identifies elements using alternative text |
| `get_by_title()` | Identifies elements using their title attribute |
| `get_by_test_id()` | Identifies elements using a test ID |
| `locator()` | Identifies elements using CSS or XPath selectors |

## 3. User-Facing Locators

### 3.1 get_by_role()

`get_by_role()` identifies an element using its ARIA role and accessible name.

**Syntax:**
```python
page.get_by_role("role", name="accessible name")
```

**Example 1 – Button**

HTML:
```html
<button type="button">Save</button>
```

Playwright:
```python
page.get_by_role("button", name="Save").click()
```

**Example 2 – Link**

HTML:
```html
<a href="/dashboard">Dashboard</a>
```

Playwright:
```python
page.get_by_role("link", name="Dashboard").click()
```

**Example 3 – Checkbox**

HTML:
```html
<label>
    <input type="checkbox">
    Remember me
</label>
```

Playwright:
```python
page.get_by_role(
    "checkbox",
    name="Remember me"
).check()
```

**Example 4 – Radio Button**

HTML:
```html
<label>
    <input type="radio" name="gender" value="male">
    Male
</label>
```

Playwright:
```python
page.get_by_role(
    "radio",
    name="Male"
).check()
```

**Example 5 – Heading**

HTML:
```html
<h1>Dashboard</h1>
```

Playwright:
```python
page.get_by_role(
    "heading",
    name="Dashboard"
).is_visible()
```

**Example 6 – Table Row**

HTML:
```html
<table>
    <tr>
        <td>Invoice_001.pdf</td>
        <td>Approved</td>
    </tr>
</table>
```

Playwright:
```python
page.get_by_role(
    "row",
    name="Invoice_001.pdf Approved"
).is_visible()
```

**Example 7 – Dropdown**

HTML:
```html
<label for="department">Department</label>

<select id="department">
    <option>Engineering</option>
    <option>Finance</option>
</select>
```

Playwright:
```python
page.get_by_label("Department").select_option(
    label="Engineering"
)
```

**Common ARIA roles:**

| Role | HTML example |
|---|---|
| `button` | `<button>` |
| `link` | `<a href="">` |
| `textbox` | Text input or textarea |
| `checkbox` | Checkbox input |
| `radio` | Radio input |
| `heading` | `<h1>` to `<h6>` |
| `combobox` | Native select or accessible combobox |
| `row` | Table row |
| `cell` | Table cell |
| `dialog` | Dialog element |

**Important:** The role and accessible name must match the element's actual accessibility information. An element's visible text and accessible name are not always identical.

### 3.2 get_by_label()

`get_by_label()` identifies form controls through their associated label, `aria-label` or `aria-labelledby` information.

**Example 1 – Label with for and id**

HTML:
```html
<label for="username">Username</label>
<input id="username" type="text">
```

Playwright:
```python
page.get_by_label("Username").fill("admin")
```

**Example 2 – Password Field**

HTML:
```html
<label for="password">Password</label>
<input id="password" type="password">
```

Playwright:
```python
page.get_by_label("Password").fill("password123")
```

**Example 3 – Label wrapping an input**

HTML:
```html
<label>
    Email Address
    <input type="email">
</label>
```

Playwright:
```python
page.get_by_label("Email Address").fill(
    "admin@example.com"
)
```

**Example 4 – aria-label**

HTML:
```html
<input type="text" aria-label="Search Documents">
```

Playwright:
```python
page.get_by_label("Search Documents").fill(
    "Invoice"
)
```

**Example 5 – aria-labelledby**

HTML:
```html
<span id="folder-label">Folder Name</span>

<input type="text" aria-labelledby="folder-label">
```

Playwright:
```python
page.get_by_label("Folder Name").fill(
    "Automation"
)
```

### 3.3 get_by_placeholder()

`get_by_placeholder()` identifies input elements using their placeholder attribute.

**Example 1 – Username**

HTML:
```html
<input
    type="text"
    placeholder="Enter username"
>
```

Playwright:
```python
page.get_by_placeholder(
    "Enter username"
).fill("admin")
```

**Example 2 – Search Field**

HTML:
```html
<input
    type="search"
    placeholder="Search documents"
>
```

Playwright:
```python
page.get_by_placeholder(
    "Search documents"
).fill("Invoice")
```

**Example 3 – Folder Name**

HTML:
```html
<input
    type="text"
    placeholder="Enter folder name"
>
```

Playwright:
```python
page.get_by_placeholder(
    "Enter folder name"
).fill("Automation")
```

**Example 4 – Exact Matching**

HTML:
```html
<input placeholder="Search">
<input placeholder="Search Documents">
```

Playwright:
```python
page.get_by_placeholder(
    "Search",
    exact=True
).fill("Invoice")
```

By default, placeholder matching can match substrings. `exact=True` requires an exact match.

### 3.4 get_by_text()

`get_by_text()` identifies an element using its text content.

**Example 1 – Success Message**

HTML:

```

```

**Example 2 – Exact Text Matching**

HTML:
```html

<button>Save Changes</button>
```

Playwright:
```python
page.get_by_text(
    "Save",
    exact=True
).click()
```

**Example 3 – Partial Text Matching**

HTML:
```html

    Document uploaded successfully. File ID: 1025
</div>
```

Playwright:
```python
page.get_by_text(
    "Document uploaded successfully"
).is_visible()
```

**Example 4 – Error Message**

HTML:
```html
<span class="error">
    Invalid username or password
</span>
```

Playwright:
```python
page.get_by_text(
    "Invalid username or password"
).is_visible()
```

**Example 5 – Menu Item**

HTML:
```html
<div class="menu">
    <span>Settings</span>
</div>
```

Playwright:
```python
page.get_by_text(
    "Settings",
    exact=True

```

**Important:** For buttons and links, prefer `get_by_role()` when their role and accessible name are available.

### 3.7 get_by_test_id()

`get_by_test_id()` identifies elements using a dedicated test ID attribute.

**Example 1 – Save Button**

HTML:
```html
<button data-testid="save-document">
    Save
</button>
```

Playwright:
```python
page.get_by_test_id(
    "save-document"
).click()
```

**Example 2 – Document Name**

HTML:
```html
<div data-testid="document-name">
    Invoice_001.pdf
</div>
```

Playwright:
```python
page.get_by_test_id(
    "document-name"
).is_visible()
```

**Example 3 – Search Input**

HTML:
```html
<input data-testid="document-search">
```

Playwright:
```python
page.get_by_test_id(
    "document-search"
).fill("Invoice")
```

**Important:** Test IDs are intended for automated testing. They are generally more stable than selectors based on styling classes.

## 9. Working with Iframes

An iframe embeds another HTML document inside the current page.

HTML:
```html
<iframe id="documentFrame"></iframe>
```

Playwright:
```python
document_frame = page.frame_locator(
    "#documentFrame"
)

document_frame.get_by_role(
    "button",
    name="Download"
).click()
```

### 9.1 CSS Inside an Iframe

HTML inside the iframe:
```html
<input id="chkSelect" type="checkbox">
```

Playwright:
```python
document_frame.locator(
    "#chkSelect"
).check()
```

### 9.2 Role Locator Inside an Iframe

HTML inside the iframe:
```html
<button>Download</button>
```

Playwright:
```python
document_frame.get_by_role(
    "button",
    name="Download"
).click()
```

### 9.3 Text Locator Inside an Iframe

HTML inside the iframe:
```html
<div>Document loaded successfully</div>
```

Playwright:
```python
document_frame.get_by_text(
    "Document loaded successfully"
).is_visible()
```

### 9.4 Practical ECM Example

```python
IF_DOC_IFRAME = page.frame_locator(
    "iframe"
)

IF_DOC_IFRAME.locator(
    "#chkSelect"
).check()
```

Replace the iframe selector with the actual unique iframe locator in your application.

For applications containing multiple iframes, identify the correct iframe before interacting with its contents.
