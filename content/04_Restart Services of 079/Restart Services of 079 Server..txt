# 079 Server – Service Restart Procedure

## 1. Connect to the 079 Server

1. Open **Remote Desktop Connection (RDP)**.
2. Enter the following connection details:
   - Username
   - Computer Name
   - Password
3. Once the credentials are successfully authenticated, you will be automatically logged in to the 079 Server through Remote Desktop Connection.

## 2. Open the Services Application

1. Click the **Start** button.
2. Search for `Services` and press **Enter**.
3. Once the Services application opens, click on any one of the services in the list.
4. Press the **V** key on your keyboard.

   This will navigate to the services starting with the letter V, allowing you to locate all the Vicisoft-related services.

## 3. Restart Vicisoft Services

Restart the following services one by one:

### 3.1 ViciECM Text Extraction Service

1. Select **ViciECM Text Extraction Service**.
2. Click the **Restart** hyperlink available on the left-hand panel.

### 3.2 ViciECM Doc Manager

1. Select **ViciECM Doc Manager**.
2. Click **Restart** to restart the service.

### 3.3 ViciECM Workflow Escalation Engine

1. Select **ViciECM Workflow Escalation Engine**.
2. Click **Restart** to restart the service.

### 3.4 ViciECM Format Converter

1. Select **ViciECM Format Converter**.
2. Click **Restart** to restart the service.

**Note:** The Format Converter service may take some time to restart.

If the Format Converter service takes too long:

1. Open **Task Manager**.
2. Navigate to the **Details** tab.
3. Locate the Format Converter process.
4. Select the corresponding process and click **End Task**.


## **4. Restart IIS**

Once all the required Vicisoft services have been restarted:

1. Close the **Services** application.
2. Open **Command Prompt (CMD)** with Administrator privileges.
3. Execute the following command:

   ```cmd
   iisreset
   ```

4. Press **Enter**.
5. Wait until the IIS reset operation completes.
6. Verify that the following success messages appear:

   ```text
   Internet services successfully stopped
   Internet services successfully restarted
   ```

**Expected Result:** IIS services are successfully restarted.

## **5. Complete the Process**

Once the `iisreset` command executes successfully:

1. Verify that both stop and restart operations are completed successfully without errors.
2. Close the Command Prompt window.
3. Log out of the **079 Server Remote Desktop Connection**.

The service restart procedure for the **079 Server** is now complete.
